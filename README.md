# JhaTech Growth - Digital Growth Advisor 🚀

An AI-powered digital growth assistant designed to help businesses and individuals improve their online presence through personalized growth strategies, marketing insights, and actionable recommendations.

JhaTech Growth uses Generative AI to analyze user requirements and provide intelligent suggestions that help users make better decisions for digital marketing, business improvement, and online growth.

---

## 🌟 Features

- 🤖 AI-powered digital growth recommendations
- 📊 Personalized business growth strategies
- 💡 Smart marketing insights and suggestions
- ⚡ Real-time AI responses using Gemini API
- 🔥 Firebase-powered backend services
- 🔐 Secure data handling and authentication support
- 🌐 Modern and responsive user interface
- 📱 Mobile-friendly design
- 🔗 WhatsApp direct communication integration
- 🎨 Clean and interactive user experience

---

## 🎯 Problem Statement

Many small businesses, startups, and individuals struggle with understanding:

- How to improve their online presence
- Which digital marketing strategies to follow
- How to attract more customers
- How to make data-driven growth decisions

JhaTech Growth solves this problem by providing AI-powered recommendations and digital growth guidance based on user requirements.

The platform works as a digital growth advisor that helps users identify opportunities and implement better strategies.

# ⚙️ Installation & Setup

## 1. Clone Repository

```bash
git clone <repository-url>
```

## 2. Navigate to Project Directory

```bash
cd JhaTech-Growth
```

## 3. Install Dependencies

```bash
npm install
```

---

# 🔑 Environment Configuration

Create a `.env` file in the root directory:

```env
GEMINI_API_KEY=your_gemini_api_key
```

# 🚀 Run Project Locally

Start development server:

```bash
npm run dev
```

The application will run on:

```
http://localhost:5173
```

# 🤖 Gemini API Integration

The application integrates Google Gemini API to generate AI-powered responses.

### Workflow:

```
User enters business requirement

        ↓

Application processes input

        ↓

Request sent to Gemini API

        ↓

AI generates recommendation

        ↓

Growth strategy displayed to user
```

---

# 📡 API Flow

## AI Recommendation Request

```
POST
Gemini API Endpoint
```

### Input:

```json
{
  "businessType": "Startup",
  "goal": "Increase online customers"
}
```

### Output:

```json
{
  "recommendation": [
    "Improve SEO",
    "Create social media strategy",
    "Run targeted campaigns"
  ]
}
```
