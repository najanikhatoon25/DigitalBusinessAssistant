# JhaTech Growth

A modern React + TypeScript landing page for the AI-driven digital growth platform assignment.

## Run locally

```bash
cd /home/sama/Desktop/jhaTech/digitalGrowthAdvisor
npm install
npm run dev -- --host 0.0.0.0
```

## Build

```bash
npm run build
```

## Deployment

The project is configured for GitHub Pages using a Vite build workflow.
